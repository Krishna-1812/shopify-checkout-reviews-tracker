    Run health

    The tracker runs every day on GitHub Actions. A failed run, or one that quietly collects nothing, opens a GitHub issue.

    Data: public reviews from apps.shopify.com. Tags: a free AI tier (Gemini or Groq) when a key is set, otherwise keyword rules. Code, data and handover notes are in the GitHub repository.
